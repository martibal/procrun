# A21 v2 rule provenance

This file records why the v2 component-engine remediation exists and what evidence may be used to justify it.

## Allowed remediation evidence

The v2 changes are justified only by material that was already exposed before the sealed post-remediation holdout is opened:

- the documented v1 limitation that deterministic phrases were Portuguese/English only;
- the A21 blind source-text adjudication over the 350-case screening pool;
- the observed source wording from the development/diagnostic material, including explicit Italian photovoltaic, battery-storage and relamping scope;
- conservative Italian equivalents for already-frozen semantic categories.

The sealed 50-case holdout is not used to select phrases, categories, thresholds or state rules.

## Explicit new category

`energy_efficiency:battery_storage`

Reason: v1 had no category capable of representing a source-explicit electrical energy-storage component. The new category remains source-span constrained and carries no procurement-state privilege.

## State logic

No OPEN/CLOSED/PARTIAL/UNRESOLVED rule is changed by taxonomy v2.
